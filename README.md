### 🔬 AlgoLens AI — AI-Powered DSA Learning Platform
A full-stack platform that unifies DSA learning, practice, AI feedback, and spaced-repetition revision into one interface.

- AI-generated topic notes, leveled hints, and code reviews (Gemini)
- Curated curriculum, in-browser code editor, and sample test cases
- Spaced-repetition queue, contribution heatmap, and topic proficiency tracking
- JWT auth with bcrypt, password reset, and role-based admin access
- AI responses cached in the database to prevent duplicate billing

**Stack:** SvelteKit 5 · TypeScript · Tailwind CSS 4 · shadcn-svelte · FastAPI · Python 3.13 · PostgreSQL · Gemini API
